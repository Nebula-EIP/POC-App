Detailed Description

A link dragged from a pin and released on empty canvas: the nodes that can be linked to the pin, offered by the node picker, and the link to the picked node once it is created.

Lists the pins of the catalog nodes that can be linked to the dragged pin, one entry per pin, labelled "Node › pin (type)".

A pin fits when CheckConnectionRule accepts it (opposite direction, same type) and its node comes from the module of the dragged node. Entries keep the catalog order, then the order of the pins in the node.

Parameters
module_nameReturns the displayed name of a module (top folder).
type_nameReturns the name of a type of the dragged node's module. May be empty, or return an empty name: the type is then shown by id.

Links the dragged pin to the picked pin of a node just created, through RequestConnection so that the usual rules and messages apply.

When the link is refused, the new node is removed from the graph (the caller removes its view), so that no unlinked node is left behind.

Parameters
new_nodeThe node created from the picked entry.
pinThe picked pin of that node.
Returns
The outcome of the connection request. On failure the faulty pin is the dragged one, since the new node is gone.
