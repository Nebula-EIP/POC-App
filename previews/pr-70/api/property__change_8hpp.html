Applies new property values to a node of the graph.

The node list capability tells which pin types the new properties give (a literal switched to float outputs a float). A connected pin never changes type: the whole change is refused, nothing is modified, and the outcome lists the connections to remove first.

Parameters
graphThe graph holding the node.
nodesNode list capability of the node's module (may be null: pins then never change).
node_idThe edited node.
changesProperties to set, applied together.
type_nameName of a data type, for the messages.
node_titleTitle of a node, for the messages.
