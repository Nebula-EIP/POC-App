Detailed Description

The project color palette: every color the editor draws with, by name, in one place.

Adding a color: one line in the section of the part of the editor it belongs to, from its hex code and an optional opacity:

inline constexpr utils::WrappedColor kMyColor = Hex(0x23252D);
inline constexpr utils::WrappedColor kMyShadow = Hex(0x000000, 0.25F);
utils::WrappedColor
Definition raylib_wrapper.hpp:88

A color can reuse another one by name (kText = top_bar::kText).

Referencing a color: palette::<section>::k<Name>, e.g. palette::canvas::kBackground.

Pin types and node accents are looked up by name (TypeColor("int"), NodeAccent("Variable", "Data")): adding one is one line in its table.
