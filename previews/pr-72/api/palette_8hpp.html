Detailed Description

The project color palette: every color the editor draws with, by name.

The values live in palette.yaml, read at start-up.

Referencing a color: palette::Get().<section>.<name>, e.g. palette::Get().canvas_.background_. Pin types and node accents are looked up by name: palette::TypeColor("int"), palette::NodeAccent("Variable", "Data").

Adding a color: one line in palette.yaml and one member (plus its entry in Palette::Fields(), palette.cpp) here. A color only added to the type_names, accent_nodes or accent_categories tables of palette.yaml needs no code.
