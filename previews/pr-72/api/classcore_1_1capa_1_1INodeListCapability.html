Get the configuration of a node instance for its current properties.

Some nodes adapt their pins to their properties (a typed literal outputs the type it holds). The editor calls this after each property change and matches the returned pins with the node's pins by position. The default implementation ignores the properties.

Parameters
typeThe node type.
propertiesThe properties of the node instance.
Returns
The configuration matching these properties.
