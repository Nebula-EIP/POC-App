Palette palette::Palette::FromYaml ( std::string_view yaml,
std::vector< std::string > & warnings )
staticnodiscard

Reads a palette from YAML text.

Colors the text leaves out keep their Default() value. A color that cannot be read (bad hex code, unknown or circular reference...) also keeps it, with a message in warnings.

Parameters
yamlThe contents of a palette file.
warningsReceives one message per ignored entry.
Exceptions
std::runtime_errorIf the text is not valid YAML.
