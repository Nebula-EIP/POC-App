The rules of a connection, shared by RequestConnection and the node picker opened from a link dropped on empty canvas, so that the picker never offers a connection that would then be refused.

Checked in this order: both ends are pins, opposite directions, two different nodes, same type.

Connects the two pins of a drag, in whichever order they were picked (output to input, or input to output).

An input accepts a single connection: the new connection takes priority and replaces the one already on the input (an output can still feed several inputs).

Rejected with a message when CheckConnectionRule refuses the pins (two inputs, two outputs, a node linked to itself, mismatching types), and on any other error raised by core::Graph::Connect.

Parameters
graphThe graph to connect in.
startThe pin the drag started from.
endThe pin the drag was released on.
type_nameResolves type names for the mismatch message. May be empty, in which case types are shown by id.
Returns
The outcome; the graph is left untouched on failure.
