Detailed Description

The menu bar drawn at the top of the window.

It is drawn in screen space, after the canvas, so pan and zoom never affect it. It spans the whole window width, whatever the window size.

Each frame, call Update() before the canvas processes its input: when it returns true the mouse belongs to the bar and must not reach the canvas. Then call Draw() after the canvas has been drawn.
