Detailed Description

A floating, searchable tree of the available nodes.

Without a search, the nodes are shown as a tree: one folder per module, then the category folders of the module ("Flow/Loops" gives Flow > Loops). Folders start closed (a single module folder starts open). A click, Enter or Right opens a folder; a click, Enter or Left closes it.

Typing a search replaces the tree with the flat list of the nodes whose name contains the text (case insensitive), without folders; names starting with the text come first.

Enter or a click on a node picks it: the picker closes and calls the callback given to Open() with the node type. Escape or a click outside closes it without creating anything.

OpenForConnection() opens it in connection mode, on a list of its own (the nodes that can be linked to a dragged pin, one entry per pin) with the same tree and search; the entries given to SetEntries() come back at the next Open().

Each frame, call Update() before anything else reads the input: while it is open the picker owns the mouse and the keyboard. Then call Draw() after the canvas has been drawn.
