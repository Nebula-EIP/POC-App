Detailed Description

Draws renderer component descriptions and owns transient widget state (focused field, text being typed, open list).

Components are rebuilt from the graph every frame: the adapter never keeps a value of its own, except the text being typed. Text and number fields are applied on Enter or when clicking elsewhere, and only when valid; Escape cancels. While a text is invalid its explanation is drawn under the field.
