Detailed Description

Represents the configuration for the editor, including paths to modules and other settings.

Read once at startup from config.yaml (see config.example.yaml). The file is optional, every key keeps its default value when it is absent, and the application never writes it.

Deprecated: when the YAML file is missing, the JSON file with the same name (config.json) is read instead and a warning is logged. This fallback will be removed.
