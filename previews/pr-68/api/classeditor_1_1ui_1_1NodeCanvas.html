Detailed Description

Represents a canvas for displaying and interacting with nodes.

Takes the render::Camera it draws and hit-tests against from the caller rather than owning one, so there is a single camera (Application's) for the whole editor — never two that could drift out of sync on pan/zoom.

◆ Update()

void editor::ui::NodeCanvas::Update ( const CanvasInput &  input)

Handles one frame of input: selection, node moves, and link drags.

A link drag released on a pin requests a connection (PopPendingConnectionRequest); released on empty canvas inside the window, it records a link drop (PopPendingLinkDrop). Released on a node body, outside the window, or while the pointer is captured, it ends without anything.
